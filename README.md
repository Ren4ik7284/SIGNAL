# SIGNAL // Minimalist Audio Player & Stream Engine

Минималистичный монохромный веб-плеер с фокусом на прямое потоковое воспроизведение (Stream URLs, онлайн-радио, локальные файлы), поиск и каталогизацию.

---

## Архитектура и дизайн

* **Палитра:** Глубокий матовый серый/графит (`#0e0e10`, `#141417`, `#1f1f24`), тонкие рамки (`#292930`), акцентный чистый белый `#ffffff` для кнопок действия. Никакого неона, градиентов или эмодзи.
* **Иконки:** Векторные монохромные SVG-иконки.
* **Управление:**
  * Полнофункциональный нижний док-плеер (Play, Pause, Prev, Next, Shuffle, Repeat All/One/Off).
  * Скраббер с плавным поиском по секундам (для треков) и индикатором `LIVE STREAM ∞` (для онлайн-станций).
  * Регулятор громкости и моментальный Mute.
  * Боковая панель очереди воспроизведения (Queue Drawer).
  * Быстрые клавиши: `Space` (Play/Pause), `←`/`→` (±5 сек), `↑`/`↓` (громкость), `M` (mute), `L` (избранное).

## Источники воспроизведения

1. **Прямые ссылки (Stream URL):**
   * Вставляйте прямую ссылку на любой аудиофайл в сети (`.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a` или поток интернет-радио).
   * Файлы воспроизводятся мгновенно через потоковую буферизацию без скачивания на диск.
2. **Готовые 24/7 радиостанции:**
   * SomaFM Drone Zone (Ambient)
   * Groove Salad (Downtempo)
   * DEF CON Radio (Electronic)
   * Secret Agent (Surf / Spy)
3. **Локальные файлы (Drag & Drop):**
   * Загрузка файлов с вашего компьютера с автоматическим определением формата и длительности.
4. **Сохранение в браузере (LocalStorage):**
   * Добавленные вами потоки и избранные треки сохраняются в локальной базе браузера.
