**SIGNAL** — современный, быстрый и независимый аудиоплеер со встроенной «Моей Волной», каталогом онлайн-радио, мультиплатформенным поиском и поддержкой оффлайн-режима. Никакой рекламы, подписок, капч и необходимости использовать VPN: аудиопотоки обрабатываются напрямую высокопроизводительным бэкендом на Rust и транскодируются в реальном времени.

## ✨ Ключевые возможности

### 🌊 Моя Волна (Smart Wave)
- **Векторная модель предпочтений**: самообучающийся вектор вкусов (энергичность, темп, акустичность, вес жанров). Модель адаптируется на лету: дослушанные до конца треки усиливают схожие направления.
- **Гибкая настройка**: переключение вайба (Все стили, Бодрый, Спокойный, Любимое), выбор языкового фильтра (Все, Только русские, Только зарубежные) и баланса источников (Моя музыка, Баланс, Больше открытий).
- **Плавный бесконечный поток**: автоматическая дозагрузка очереди перед окончанием трека. Встроенная защита от повторений и быстрое исключение неподходящей музыки.

### ⚡ Мультиплатформенный стриминг
- **Audius**: интеграция с открытой платформой независимых авторов со всего мира. Ежедневные релизы треков (Phonk, Electronic, Lo-Fi, Hip-Hop, Rock) со сверхбыстрым прямым стримингом без DRM.
- **SoundCloud**: доступ к миллионам треков, ремиксов и эксклюзивных релизов без ограничений.
- **YouTube**: воспроизведение по ссылкам и умный резервный поиск аудио без блокировок датацентров.
- **Онлайн-радио**: каталог мировых радиостанций (Record, Europa Plus, SomaFM и др.) с фильтрацией по жанрам и возможностью добавлять свои потоки.

### 📥 Оффлайн-режим и PWA
- Скачивание любого трека в локальное хранилище браузера (IndexedDB) в один клик.
- Полноценная работа приложения и воспроизведение сохраненной музыки без доступа к сети.
- Поддержка стандартов Progressive Web App: приложение устанавливается на смартфон или рабочий стол ПК как нативная программа.

### ☁️ Облачная синхронизация
- Синхронизация библиотеки треков, плейлистов, избранного и настроек волны между всеми вашими устройствами.
- Быстрая авторизация по логину/паролю или через Google.

### 🎛️ Эстетика и управление
- **Строгий дизайн**: минималистичная темная палитра в стиле глубокого монохрома (`#111114` / `#18181b` / `#fafafa`) без навязчивого неона и радужных градиентов.
- **Аппаратная интеграция MediaSession**: управление воспроизведением со шторки Android/iOS, экрана блокировки и мультимедийных клавиш клавиатуры или наушников.
- **Умный 10-полосный эквалайзер** с готовыми пресетами (Bass Boost, Acoustic, Electronic, Rock, Vocal и др.).

## 🚀 Быстрый запуск через Docker Compose

Самый простой способ поднять проект локально — использовать готовый `docker-compose.yml`:

```bash
# Клонируйте репозиторий
git clone https://github.com/Ren4ik7284/SIGNAL.git
cd SIGNAL

# Запустите сервисы
docker compose up --build -d
```

- **Frontend** будет доступен по адресу: `http://localhost:4200`
- **Backend** будет доступен по адресу: `http://localhost:8085`

Остановка контейнеров:
```bash
docker compose down
```

## 🛠️ Ручной запуск для разработки

### 1. Системные требования

Перед запуском убедитесь, что в системе установлены:
- **Node.js** версии 20+ и менеджер пакетов **npm**
- **Rust** и **Cargo** (актуальная стабильная версия)
- **FFmpeg** (требуется бэкенду для стриминга аудио)
- **yt-dlp** (требуется для извлечения аудиопотоков)

#### Установка зависимостей в Ubuntu / Debian:
```bash
sudo apt update
sudo apt install -y ffmpeg nodejs npm cargo
# Установка актуальной версии yt-dlp
sudo wget https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -O /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp
```

#### Установка зависимостей в macOS (Homebrew):
```bash
brew install ffmpeg node yt-dlp rust
```

#### Установка зависимостей в Windows:
- Установите Node.js с официального сайта: [nodejs.org](https://nodejs.org)
- Установите Rust: [rustup.rs](https://rustup.rs)
- Установите FFmpeg и yt-dlp через `winget`:
  ```powershell
  winget install Gyan.FFmpeg
  winget install yt-dlp.yt-dlp
  ```

---

### 2. Запуск бэкенда (Rust)

```bash
cd backend

# Проверка сборки
cargo check

# Запуск сервера разработки
cargo run
```

Сервер поднимется на `http://localhost:8085`. База данных SQLite будет инициализирована автоматически в локальной директории или `/data`.

---

### 3. Запуск фронтенда (Angular)

Откройте второй терминал:

```bash
cd frontend

# Установка зависимостей
npm install

# Запуск dev-сервера с hot-reload
npm start
```

После компиляции приложение откроется по адресу `http://localhost:4200`.
